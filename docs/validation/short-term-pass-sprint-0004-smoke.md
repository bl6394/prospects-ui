**Defects and corrections during E2.**
1. **Product defect (fixed, UI `4d5a8e8`):** at 375 px the sidebar "Valid" value (`.srow .v`, `white-space: nowrap`) pushed the recognized and done screens to 460 px. `.srow.valid .v` now wraps under its label; `layout.test.ts` pins it. The first-run screenshot showed the sentence running off the Receipt card.
2. **Product defect (fixed earlier the same day, UI `0c920fa`, found by the new page suite, not by E2):** a `contractVersion` mismatch on the very first bootstrap never re-bootstrapped after the one-shot restart, and the toggling `busy` flag re-bootstrapped over the pending error (four requests instead of two). The bootstrap effect now keys on `epoch` and skips while an error is pending.
3. **Environment gap, not a defect:** the standalone origin `http://guestpass.localhost:3000` had to be added to `STP_ALLOWED_ORIGINS` locally (helm D1 does this for dev); without it the page renders the unavailable block because `POST /checkouts` is refused by the origin allowlist.
4. **Script artifacts:** `window.guestPass` is defined with non-enumerable properties (JSON-serialising it yields `{}`), and the state route nests the order under `checkout.order` and the consent snapshot under `purchases[].consents`.
